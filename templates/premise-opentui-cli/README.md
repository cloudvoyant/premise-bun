# premise-opentui

A minimal Bun terminal interface built with [OpenTUI](https://opentui.com/).

## Run

```bash
bunx premise-opentui
```

Use the left and right arrow keys to change the counter. Press `q` or Ctrl-C to exit.

## Develop

```bash
mise run install
mise run test
mise run build
mise run run
```

The package requires Bun 1.4.2 or later.
